# ADR-001: Core Web Vitals & Technical SEO Priority Strategy for Next.js App Router

## Status

Accepted

## Date

2026-07-28

## Context

Levemente AI is a Next.js (App Router) application for AI-powered meal tracking, macro calculation, and dietary insights. 95% of the logged-in app experience requires authentication, while marketing, landing pages (`/`, `/plans`), and public pages serve as the primary organic acquisition surface. The platform currently lacks advanced SEO metadata (dynamic `generateMetadata`, OpenGraph, Twitter Cards, `sitemap.ts`, `robots.ts`, structured data JSON-LD) and has unoptimized Core Web Vitals (LCP, CLS, INP, TTFB).

## Decision

We will prioritize a **Technical SEO & Core Web Vitals First** strategy. All public pages will be rendered using Next.js App Router static server components (SSG/ISR) with dynamic metadata and full Schema.org structured data (`SoftwareApplication`, `WebApplication`, `FAQPage`). Public shareable meal reports and SEO content hubs (calculators, comparative pages, evergreen guides) will be built on server-rendered routes without requiring upfront user onboarding, protecting authenticated routes while maximizing crawlability and organic conversion.

## Alternatives Considered

### Alternative 1: Programmatic SEO Database First (pSEO)

- **Description**: Instantly generate thousands of public food/ingredient pages from nutrition databases.
- **Pros**: Rapidly increases indexed URL volume.
- **Cons**: High risk of thin content penalties from search engines if technical foundation and Core Web Vitals are unoptimized.
- **Why rejected**: Technical SEO and Core Web Vitals performance must be rock-solid first before indexing large volumes of programmatic pages.

## Consequences

### Positive

- Ensures Lighthouse 95+ score across LCP, CLS, INP, and TTFB on Next.js 16 App Router.
- Enables rich snippets in Google Search & AI Overviews (GEO - Generative Engine Optimization).
- Establishes clean Clean Architecture abstraction wrappers for metadata and structured data generators.

### Negative

- Requires initial refactoring of layout scripts and font loading strategies.

### Risks

- Core Web Vitals regression during dynamic user interactions.
- Mitigation: Continuous integration Cypress + Lighthouse assertion checks.

## Implementation Notes

- Implement dynamic metadata factory helper under `utils/seo/metadata.ts`.
- Add JSON-LD schema builders conforming to Schema.org standards.
- Build server-side `sitemap.ts` and `robots.ts` using Next.js App Router conventions.
